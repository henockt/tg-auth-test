## tg-auth-test

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app). It showcases a seamless authentication method that can used in a Telegram Mini App environment. It uses `@telegram-apps/sdk` and `@tma.js/init-data-node`.

Before testing, set `BOT_TOKEN` environment variable.
 
Check out a live version [here](https://t.me/tg_auth_test_main_bot). (https://t.me/tg_auth_test_main_bot)
